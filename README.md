# GreenSense
GreenSense is an ESP32-based IoT prototype that monitors soil moisture, light, temperature and humidity. It classifies sensor readings, compares related parameters to identify normal or unusual conditions, generates an inference with a suggested solution, and publishes the result as JSON through MQTT. The prototype is tested in Wokwi.
